Auto Aim file-write probe retired

Do not edit GSPro’s live currentRound.dat file to test Auto Aim. A browser write can race with GSPro’s own updates and may overwrite live game state. This probe has been disabled. No code on this page reads or writes your files.

Chrome screen sharing can read GSPro pixels, but it cannot independently inject clicks or keyboard controls into the GSPro desktop application. The previously tested OS-level click was performed with local development code, not by Chrome.

The isolated branch retains the reusable pixel closed-loop controller as research. Automatic actuation still requires either an actual GSPro-supported command interface or a local actuator, such as a small helper. Production Live Caddie was not modified.
