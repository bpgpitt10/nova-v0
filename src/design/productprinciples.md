# Product Principles

This product is not a shot tracker. It is a **decision engine**.

Primary goal:
Answer: "What should I trust right now?"

Core concepts:
- Caddie Score = numeric trust (0–100)
- Caddie Call = decision guidance
- Insights = why the score exists

Rules:
- Always prioritize decision clarity over raw data
- Always show interpretation, not just metrics
- Avoid dashboards that require user thinking
- Output should feel like a caddie, not an analyst

Hierarchy:
1. Decision (Caddie Call)
2. Trust (Caddie Score)
3. Explanation (Insights)
4. Supporting data

Never invert this hierarchy.
